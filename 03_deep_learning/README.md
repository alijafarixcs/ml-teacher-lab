# 03 — Deep Learning

This section builds neural networks from scalars, vectors, and tensors through backpropagation, convolution, recurrence, gated units, attention, and regularization. Foundational operations are implemented with NumPy; model-oriented lessons use CPU-first PyTorch and display tensor shapes, parameter counts, training and validation loss, and evaluation metrics.

Work in filename order because later notebooks reuse concepts—not hidden runtime state—from earlier lessons.
