# 01 — Supervised Learning

Supervised learning uses examples containing both features and known targets. This section moves from the shared prediction workflow to regression, classification, ensembles, careful evaluation, and an end-to-end capstone.

Recommended order:

1. Supervised-learning overview
2. Linear regression
3. Logistic regression
4. K-nearest neighbors
5. Naive Bayes
6. Decision trees
7. Random forests
8. Support vector machines
9. Gradient boosting
10. Model evaluation and selection
11. Supervised capstone

Every algorithm lesson uses a transparent NumPy implementation before its scikit-learn counterpart and ends with conceptual, mathematical, and coding exercises plus solutions.

The [required mathematics coverage map](MATHEMATICS_MAP.md) shows exactly where every topic from the course specification is first introduced and where it is reinforced. Topics are taught at their natural point of use instead of front-loading advanced notation.

Coverage includes multiple linear regression, classification probability, Euclidean and Manhattan distance, Bayes' theorem, entropy and information gain, margins and regularization, bias versus variance, underfitting and overfitting, train/validation/test discipline, cross-validation, hyperparameter tuning, feature scaling and engineering, data leakage, class imbalance, and the full required regression and classification metric sets.
